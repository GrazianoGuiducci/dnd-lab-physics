# Regenerative Physics Lab architecture

The current Lab is developed in MM-DND. This document describes its mechanisms
from the source owner's active guide and public projection. The Python package
in this repository implements the public reader only.

## Field, attention and occurrence

The reachable field can contain scientific sources, instruments, simulations,
questions, prior effects, competences and archives. Reachability does not put
every object into attention. A temporary projection exposes a situated subset
with its source envelopes and recorded relations. Unexpressed direct relations
remain unexpressed; a relational matrix does not invent a missing law.

An occurrence receives the present conditions and returns its resultant. The
current occurrence transport contract is `mm_dnd.lab_regenerative_occurrence.v0.3`:
schema, event identity and a non-empty resultant. Optional provenance,
conditions and effects remain optional carriers. An output transport failure
stays a process incident and is not repaired into a scientific finding.

The first impression can open autological questioning. When that changes what
a later field can recognize, the transformation may persist as competence.
This relation does not prescribe a fixed number of questions, phases, topics
or successful discoveries.

## Resultant, field effect and memory effect

These are three distinct relations. A complete resultant does not require an
opening or retained memory. A field effect can open, preserve or cool a form;
a memory decision can retain, cool or leave no active residue. Cooling keeps
history recoverable without making a form permanently present.

The public `resultant_carrier.value` preserves the original JSON form. An
object, array or unfamiliar expression must not be reduced to an empty
`statement` compatibility field. `not_expressed` describes an absent legacy
view, not an absent resultant. The offline reader preserves all original keys.

## Continuity and memory

The operational continuum preserves exact occurrence deposits. Selective
competence memory carries retained transformations across movements. The
public projection is derived output; it does not replace that memory.

The source mechanism distinguishes exact repeated content from distinct
retained forms even when they share a producer label. Cold records remain
available without acquiring attention through age, volume or recency. Changes
to relevant source content, recognition conditions or the researcher contract
can renew a temporary projection. Merely renaming a wake does not.

A finite wake horizon controls whether another occurrence can open. Each
already opened occurrence has its own completion boundary. A local return to
potential does not declare the possibility field exhausted. Operational
anti-replay protects an occurrence identity rather than prohibiting future
research.

## Public projection and exact contact

The source-owned projector emits the public corpus consumed by the website.
It excludes private prompts, paths, provider logs, secrets and raw provider
output. It can include an exact `field_transition`: selected object,
source-event contacts and activated competence identifiers recorded for that
occurrence. A consumer must not substitute chronological adjacency for a
missing contact.

`physics_lab trace` follows those recorded earlier contacts by matching both
event index and identity. Unavailable or conflicting contacts stay unresolved.
An activated competence identifier is readable metadata, not the private
competence payload or independent proof that learning caused an improvement.

## Executable scope in this repository

| Mechanism | Available here |
| --- | --- |
| Read a public projection and bind its exact bytes | Yes: `verify`, `fetch` and SHA-256 receipts. |
| Preserve and inspect open resultants | Yes: `event`, exact JSON and offline HTML report. |
| Follow recorded contacts and compare snapshots | Yes: `trace` and `compare`. |
| Start an MM-DND occurrence or reconstruct its private memory | Remains with the operational owner; no such controller is shipped here. |
| Run the separate D-ND_LAB engine | Follow its own installation and domain contracts. |

Downloading the corpus reproduces a **public reading**. It cannot reproduce a
provider invocation, inspect unexposed inputs, verify unavailable deposit
bytes, or establish a causal learning effect. These limits are properties of
the available evidence, not statements about what future research can do.
